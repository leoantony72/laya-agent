# Document Generation Samples

Generated by the measured PDF/PPTX layout engines. Both files passed automated
validation and every page/slide preview was inspected.

| File | Contents |
|---|---|
| `sample-report.pdf` | A4 corporate report: title, table, wrapped long URL, Unicode, web image, caption, credit, footer, page number |
| `sample-multipage.pdf` | 3-page academic report: paragraph/table continuation, repeated table headers, image + close on the final page |
| `sample-deck.pptx` | 16:9 editable deck: title, bullets, table, native bar chart, image, process diagram, quote, closing, notes |
| `sample-report_validation/` | Rendered PDF pages used for visual QA |
| `sample-multipage_validation/` | Rendered pages for the multi-page report |
| `sample-deck_slides/` | Rendered slide previews used for visual QA |

## Validation results

- PDF (`sample-report.pdf`): 1 page, 0 errors, 0 warnings; rendered at
  595.28 × 841.89 pt (A4).
- PDF (`sample-multipage.pdf`): 3 pages, 0 errors, 0 warnings; table headers
  repeat and the image/close stay on the final page.
- PPTX: 8 slides, 13.333 × 7.5 in (16:9), 0 errors; one disclosed limitation:
  no PowerPoint/LibreOffice renderer is installed, so the built-in preview
  renderer (PIL, approximated charts) was used for visual QA.
