# Status Synthesis (3P / Friday Update)

## Goal

Turn scattered legal-team activity into a short, factual status update.

## 3P Format

- **Progress** — what was completed since the last update, with document names
  and dates.
- **Plans** — what will be completed next, with owners and target dates.
- **Problems** — blockers, missing information, external dependencies, and
  decisions needed.

## Rules

1. Every item must be traceable to a document, message, or explicit user
   statement. If it is an inference, label it `assumption`.
2. Prefer short verbs and concrete nouns. No praise, no filler.
3. Group by matter or workstream, not by person, unless the user asks for a
   people view.
4. Put decisions needed at the top.
5. Mark items that slipped from the previous update and say why.

## Output Format

```
# Week of <date>

## Decisions needed
- ...

## Progress
- <Matter>: <result> (<document>, <date>)

## Plans
- <Matter>: <next action> — owner, due date

## Problems / risks
- ...

## Asks
- ...
```

## Weekly-newsletter variant

When the user asks for the Friday newsletter, add:
- a one-paragraph "what changed this week" summary,
- a "watch list" of three items,
- links or file paths for every cited document.

## Rules

- Never fabricate a completion date or an owner.
- If the source notes are thin, say "insufficient source material" and list
  what is missing.
