# Solo Standup

## Goal

A 60-second update that keeps a solo founder honest about progress.

## Format

```
Yesterday: <shipped or moved>
Today: <one outcome, not a task list>
Blocked by: <one blocker or "none">
Metric watch: <one number and its trend>
```

## Rules

- One outcome per day. A list of five tasks is not a standup.
- "Research" is not an outcome unless it produced a decision or artifact.
- Name the blocker and the next action, not just the feeling.
- If nothing shipped, say what was learned and what changes today.
- Keep it under 100 words.

## Output

The four-line update, plus one sentence on the highest-leverage next action.
