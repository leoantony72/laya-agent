# Launch Post

## Goal

Announce what shipped without hype that cannot be backed up.

## Structure

1. **Hook** — the user problem or the concrete result.
2. **What changed** — one or two sentences.
3. **Who it is for** — be specific.
4. **Proof** — a demo, number, screenshot, or quote you actually have.
5. **How to try it** — one link and one action.
6. **Ask** — a specific reply, not "thoughts?".

## Rules

- Lead with the user, not the technology.
- Remove adjectives that cannot be verified ("revolutionary", "10x").
- One call to action.
- If the launch is a waitlist, say so up front.
- Keep a short version under 280 characters and a long version for the post.

## Output

Two versions: short post and a longer thread/post, plus a one-line reply prompt.
