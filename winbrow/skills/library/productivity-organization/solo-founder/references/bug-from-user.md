# User-Reported Bug

## Goal

Turn a vague user complaint into a reproducible issue and a honest response.

## Triage

1. **Restate the symptom** in one sentence.
2. **Get the environment** — app version, OS, browser/device, account type.
3. **Get the steps** — what they did, what they expected, what happened.
4. **Get evidence** — screenshot, error text, timestamp, request ID.
5. **Reproduce** — try the exact steps. If you cannot, say so.
6. **Classify** — bug, missing feature, confusion, or external outage.
7. **Respond** — acknowledge, state what you know, give the next update time.

## Rules

- Never blame the user.
- Do not promise a fix date you cannot meet.
- Do not close as "works for me" without explaining what you tried.
- Protect the user's privacy; redact tokens, emails, and payment data.
- If it is a security issue, move to a private channel immediately.

## Output

An issue summary (steps, expected, actual, environment, evidence), a severity,
and a customer reply under 120 words.
